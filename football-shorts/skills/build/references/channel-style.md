# Channel fit (The Football Adda, @footballaddaclub)

If `${CLAUDE_PROJECT_DIR}/yt-insights/style.md` exists, read it: it is the live
rulebook, built from the channel's own analytics, and it wins over this summary.
The summary below is here so the skills still work when that file is absent.

**Format.** 13–30 s. Open on the moment itself by second 2 (no still, no title
card first: viewers drop in the first 3 s). Loop: the last beat should cut back
into the first. Text changes every 1.5–2.5 s. Player-led beats club commentary.

**Titles.** 25–45 characters, player name, one claim + one emotion, CAPS on one
punch word, an emoji pair (💀😂 / 😭❤️ / 🤯😭 / 🇰🇿⚡️), no questions, no
transfer-fee talk. Full player names in the description for search.

**Hashtags.** `#football #footballshorts` always; add `#chelsea #cfc` only on
Chelsea clips, otherwise player + club tags. 4–6 total.

**Slots (IST).** Tue/Wed/Thu 17:30–20:00, Sat 18:00. Never 13:00.

**Target metrics.** "Stayed to watch" above 50 %; average view duration above
60 % of length. When a clip is over 35 s, say so and offer the shorter cut.

**Sound.** Mute or duck official broadcaster commentary; use crowd noise from the
same match as a bed, or a sound from the Shorts "Add sound" library at upload
time. Keep any music bed low if the user adds voice.
