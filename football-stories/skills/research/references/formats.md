# Thirteen story formats (condensed from the research report §03)

Templates, not topics: a fixed beat structure a fitting story drops into. Lengths assume
~2.6–2.8 words/s before pacing. For this channel keep every script to 20–30 s after pace 0.93
(about 65–75 words). Hypotheses, not proven winners: the 24-video experiment plan (report §10)
tests F1, F4, F6 and F9 first.

| # | Format | Beats | Hook formula | Cards (templates.md) | Footage |
|---|---|---|---|---|---|
| F1 | Hidden Number | Number hook → what it means → why it's rare → comparison → payoff | "[Player] has now [done X] against [N/N]…" / "[N]. That's how many…" | stat_compare, stat_stack, headline_card | none |
| F2 | How It Really Started | "This goal started 12 s earlier" → rewind → touch 1 → touch 2 → decisive action → insight | "Everyone watched [finisher]. Watch [creator]." | (pitch diagram template not built yet) | low |
| F3 | Obvious Question | "Why can't X just Y?" → why it matters → obstacles 1–3 → verdict | "[Club] is [big]. So why [limitation]?" | rule_card, stat_stack | none |
| F4 | Myth vs Record | The myth → "the record says otherwise" → what happened (1, 2) → overlooked fact → verdict | "Everyone says [claim]. That's half true." | timeline, quote_card, headline_card | none |
| F5 | Case File | Name, year, place → ordinary detail → "But…" → turning point → outcome → echo | "[Year]. [City]. A [age]-year-old [role] called [name]…" | timeline, name_plate | none–low |
| F6 | Hidden Context | Surprising constraint → who → the rule → what he did meanwhile (3 facts) → where he is now → tag | "[Club] agreed to sign him in [date]. He wasn't allowed to join until [date]." | calendar_gap, name_plate, rule_card, stat_stack, transfer_path, headline_card (Satpayev) | none |
| F7 | Rise, Fall, Return | Peak in one line → pivot → decline in 3 facts → return or thesis → landing line | "[Player] was world-class. Then [X]." | timeline, stat_compare | none–low |
| F8 | Tactics in 20 s | "Watch [off-ball player]" → freeze → shape → name the idea → replay | — | (diagram template not built yet) | low–med |
| F9 | On This Day | "[N] years ago today" → setup (2 facts) → the moment (2–3 beats) → consequence → name reveal | "[N] years ago today, …" | calendar_gap, timeline, headline_card | none–low |
| F10 | It Happened Before | This week's moment → "this happened before" → then vs now → the difference → what it predicts | "[This week]. The last time this happened was [year]." | stat_compare, timeline | low |
| F11 | Quote Unpacked | Quote card → what he actually said → 2 facts of context → what happens next | "[Manager] just said this about [player] in public." | quote_card, stat_stack | none |
| F12 | Absurd But True | Impossible premise → "this is real" → how → ridiculous detail → kicker | — | rule_card, timeline (stylised own illustration only; never photoreal real players) | none |
| F13 | Voice of the Subject | Narrator setup → subject's own words → diagram → close | — | — | **high rights risk: only with official material you have permission for** |

Fit by purpose (report §03): breaking news → F1, F3, F10, F11; evergreen → F1, F3–F7, F12;
historical → F4, F5, F9; tactical → F2, F8; funny → F12.

Hook rules that held across the research: say the constraint or the number in the first
line; name the player early (or hold the name for a reveal in F6); end on a short payoff line
that loops back ("Remember the name.").
